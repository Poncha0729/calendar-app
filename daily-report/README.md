# 日報・日次決算テンプレート（年商1000億円への10年計画）

毎日の日報・営業実績・日次決算（売上・原価・経費・利益・現預金）・日課チェックを1枚のシートに入力して提出し、「日次ログ」に1日1行ずつためていくスプレッドシートです。ためたデータから、1か月分の日報（月間日報）、月次集計、10年計画（年商1000億円からの逆算）の実績が自動でまとまります。

| ファイル | 内容 |
| --- | --- |
| `daily_report_template.xlsx` | テンプレート本体（Googleスプレッドシート・Excelで開ける） |
| `gas/Code.gs` | 提出ボタン用の Google Apps Script（メニュー「日報」を追加する） |
| `build_template.py` | テンプレートを作るスクリプト。項目や初期値を変えて作り直すときに使う |

## シート

| シート | 役割 | いつ使うか |
| --- | --- | --- |
| 使い方 | 毎日の流れ・最初の設定・セルの色の意味 | 最初に読む |
| 本日の日報 | 毎日の入力画面。日報・営業実績・日次決算・日課チェック・振り返り（KPT）・明日のTop3 | 毎日 |
| 月間日報 | 提出した日報を1か月分、本日の日報と同じ項目の並びで1日1列に表示。月計・月目標・達成率つき | 見るだけ（表示する月は変更可） |
| 毎日やること | 年商1000億円に向けて毎日やる16項目と、週・月にやること | 必要に応じて見直す |
| 経費ログ | 費用を1件1行で記録。科目が「原価：」で始まる費用は売上原価、それ以外は販管費として集計 | 費用が出たとき |
| 案件パイプライン | 案件ごとのフェーズ・見込金額・次のアクションと期日。期日を過ぎた案件は色がつく | 商談が動いたとき |
| 月次集計 | 月ごとの売上・粗利・営業利益・営業数字・日課の実行率 | 見るだけ（表示する年目は変更可） |
| 10年計画 | 1〜10年目の売上目標と実績、必要な受注件数・商談数・営業担当者数の逆算 | 見るだけ（重点テーマは書き換え可） |
| 日次ログ | 提出した日報が1日1行でたまる記録 | 提出時に自動 |
| 提出データ | 日次ログに送る1行分のデータ（自動作成） | 触らない |
| 設定 | 目標・前提条件（単価・受注率など）・勘定科目などの選択肢 | 最初に1回（毎月見直す） |

入力するのは薄い黄色のセルだけです。白いセルは自動計算、緑の文字はほかのシートからの参照です。

## 最初の設定（1回だけ）

1. Googleドライブに `daily_report_template.xlsx` をアップロードし、Googleスプレッドシートで開く（Excel形式のまま開いた場合は「ファイル」→「Google スプレッドシートとして保存」）。
2. 「ファイル」→「設定」で、タイムゾーンを「(GMT+09:00) Tokyo」にする。変換したファイルは米国時間になっていることがあり、そのままだと提出日時や期日の判定が日本時間とずれる。
3. 「設定」シートの薄い黄色のセルを自分の数字にする（計画開始日、1年目の売上目標、平均受注単価、受注率、商談化率など）。初期値は仮の値。
4. 「毎日やること」の項目・短縮名・目安を、自分の事業に合わせて書き換える（本日の日報・日次ログ・月次集計に反映される）。
5. 提出ボタンを使う場合は、Apps Script を入れる。
   1. 「拡張機能」→「Apps Script」を開き、最初からあるコードを消して `gas/Code.gs` の中身を貼り付けて保存する。
   2. 「プロジェクトの設定」（歯車のアイコン）で、タイムゾーンが東京になっているか確認する（リマインドの時刻の基準）。
   3. スプレッドシートを再読み込みすると、メニューに「日報」が表示される。初回だけGoogleの承認画面が出るので、自分のアカウントで許可する。
6. 提出時にメールも送る場合は、「設定」の提出先メールアドレスを入力する。毎晩の未提出リマインドは、メニュー「日報」→「毎日のリマインドを設定」（時刻は「設定」のリマインドの時刻）。

Apps Script を使わない場合は、「提出データ」シートの2行目（A2〜AZ2）をコピーし、「日次ログ」の最終行の下に値のみ貼り付け（Ctrl+Shift+V）すると提出になります。Excel で使う場合もこの方法です（MAXIFS 関数を使っているため Excel 2019 以降）。

## 毎日の流れ

1. **朝**：「本日の日報」で日付を確認し、前回決めた今日のTop3と売上目標を見る。「毎日やること」で今日の行動を決める。
2. **日中**：費用が出たら「経費ログ」に1件1行で記録する。商談が動いたら「案件パイプライン」のフェーズと次のアクションを更新する。
3. **夜**：「本日の日報」に売上・営業実績・日課の結果（○△×）・振り返り（KPT）・明日のTop3を入力する。売上原価・販管費・利益は経費ログから自動で計算される。
4. **提出**：メニュー「日報」→「本日の日報を提出」。日次ログに1行追加され、入力欄を空にして翌日の日付に進められる。同じ日付をもう一度提出すると、上書きするか確認が出る。
5. **週に1回**：「月間日報」でその月の日報を1日1列で見返す。「月次集計」で売上・利益・日課の実行率を、「10年計画」で今年の目標との差を確認する。

## 月間日報（1か月分を1シートで見る）

「本日の日報」で提出した日報が、本日の日報と同じ項目の並びで1日1列ずつ（最大31日）並びます。このシートには入力しません。提出していない日は空欄です。

- 「表示する月」（B2）が空欄なら、「本日の日報」の日付の月を表示します。ほかの月を見るときは、B2にその月の日付を入力します（例：2026/10/1）。
- 左側の列に、項目ごとの月計（合計・平均・○の回数）、月目標（10年計画から逆算）、達成率を表示します。
  - 月計の欄：現預金残高は月末時点の残高です。
  - 達成率の欄：日課は「○の回数÷日報を提出した日数」です。Top3は「○の回数÷結果を入れた日数」です。
- 月ごとに残したいときは、シートをコピーして、B2にその月の日付を入れます。

## 年商1000億円に向けて毎日やること

10年目の目標 年1,000億円は、1日あたり約2.7億円です。毎日の行動を次の16項目に分け、「本日の日報」で毎日 ○（できた）・△（一部）・×（できなかった）をつけます。

1. **目標から逆算して今日の数字を決める**（数字・朝5分）
   - やること：10年計画→今年→今月の目標と実績の差を確認し、今日の売上と行動件数の目標を決める
   - 理由：10年目の目標を365で割ると、1日に必要な売上がわかる（年1000億円なら1日約2.7億円）。毎日差を確認しないと、差は月末まで気づかれないまま広がる
2. **日次決算を締める**（数字・夜10分）
   - やること：今日の売上・原価・経費・現預金残高をその日のうちに確定し、日報で提出する
   - 理由：急成長中の会社は黒字でも資金が尽きることがある。利益と現金を毎日つかんでいれば、手を打つのが早くなる
3. **最重要タスクを午前中に終わらせる**（売上・午前中）
   - やること：前回の日報で決めたTop3のうち、売上に最も効く1つを最初に片付ける
   - 理由：急ぎではないが重要な仕事は、後回しにするといつまでも終わらない。売上を動かす仕事を1日の最初に固定する
4. **新規アプローチを目標件数やる**（売上・本日の日報の目標件数）
   - やること：架電・DM・訪問・紹介依頼などで、見込み客との新しい接点をつくる
   - 理由：受注は商談から、商談は接点から生まれる。入口の件数が足りなければ、成約率が高くても売上は伸びない
5. **既存顧客と話す**（売上・1社以上）
   - やること：最低1社と話し、課題・不満・追加の要望を聞く。満足している顧客には紹介を頼む
   - 理由：既存顧客からの追加受注と紹介は、新規開拓より獲得コストが低い。解約の兆しにも早く気づける
6. **商談を前に進める**（売上・全案件）
   - やること：案件パイプラインを更新し、すべての案件に次のアクションと期日を入れる。問い合わせや依頼には24時間以内に返す
   - 理由：次の一手が決まっていない案件は失注しやすい。止まっている案件をゼロにする
7. **仕事を1つ仕組み化する**（仕組み・1つ）
   - やること：今日やった仕事から1つ選び、マニュアル・テンプレート・チェックリストにして共有する
   - 理由：年1000億は自分1人では届かない。誰がやっても同じ成果が出る手順があれば、新しく入った人が早く戦力になる
8. **仕事を1つ手放す**（仕組み・1つ）
   - やること：自分がやらなくてよい仕事を1つ、人に任せる・自動化する・やめる
   - 理由：社長の時間は増やせない。手放して空いた時間を、売上・採用・提携に使う
9. **採用の接点を1つつくる**（組織・1件）
   - やること：候補者と話す、スカウトを送る、知人に紹介を頼む、採用ページを直す、のいずれかをやる
   - 理由：1人あたり売上が1億円でも、年1000億には1,000人が必要になる。採用は毎日進めないと間に合わない
10. **メンバー1人と向き合う**（組織・1人）
   - やること：1on1・承認・感謝・フィードバックのいずれかを1人に行う
   - 理由：採用しても定着しなければ組織は大きくならない。育成と定着が採用の成果を決める
11. **顧客の声から改善を1つ実行する**（商品・1つ）
   - やること：商品・サービス・業務のどこかを、顧客の声をもとに1つ直す
   - 理由：毎日1つの改善は1年で約365個になる。競合との差は日々の改善の積み重ねでつく
12. **1つ発信する**（発信・1本）
   - やること：SNS・ブログ・導入事例・採用広報などで1つ発信する
   - 理由：発信は問い合わせ・採用応募・提携の相談を生む。知られていない会社には相談が来ない
13. **提携・資金・人脈に1手打つ**（拡大・1件）
   - やること：金融機関・投資家・提携先・業界のキーパーソン・M&A候補のいずれかに連絡するか会う
   - 理由：年1000億には自社の営業だけでなく、資金調達・提携・M&Aによる成長が必要になる。関係づくりは必要になる前に始める
14. **30分学ぶ**（学び・30分）
   - やること：経営・財務・業界の動向や、先に年商1000億に届いた会社の事例を学び、1つを自社に当てはめる
   - 理由：会社の規模が10倍になるたびに、経営者に必要な知識と判断が変わる
15. **体調を整える**（自己管理・睡眠7時間・運動20分）
   - やること：睡眠を7時間とり、運動する。体調を5段階で記録する
   - 理由：10年間、判断の質を落とさずに働き続けるための土台になる
16. **日報を書いて提出する**（振り返り・夜15分）
   - やること：今日の結果を記録し、KPT（続けること・課題・次に試すこと）と明日のTop3を書いて提出する
   - 理由：何が効いたかを毎日記録すると、成果が出たやり方を再現できる。記録がなければ振り返りは記憶頼みになる

### 週に1回・月に1回やること

| 頻度 | やること |
| --- | --- |
| 毎週 | 月次集計で日課の実行率を見て、続かない日課の原因を1つ決めて手を打つ |
| 毎週 | 案件パイプラインを全件見直し、止まっている案件の次の一手を決める |
| 毎週 | 翌週の最重要テーマと売上目標を決める |
| 毎月 | 月次集計で売上・粗利・営業利益を目標と比べ、差の原因を書き出す |
| 毎月 | 設定シートの平均受注単価・受注率・商談化率を実績に合わせて更新する |
| 毎月 | 採用・組織の計画を、10年計画の必要な営業担当者数と比べて見直す |

## 10年計画（初期値）

「設定」の1年目の売上目標（初期値 2億円）と10年目の売上目標（1,000億円）から、毎年同じ成長率で伸ばした場合の目標を計算します。初期値では、必要な成長率は毎年約99.5%（ほぼ毎年2倍）です。

| 年目 | 売上目標 | 1日あたり | 必要な受注件数（年） | 営業担当者数の目安 | 重点テーマ（例） |
| --- | ---: | ---: | ---: | ---: | --- |
| 1年目 | 2.0億円 | 55万円 | 400件 | 0.7人 | 再現できる売り方を確立する |
| 2年目 | 4.0億円 | 109万円 | 798件 | 1.5人 | 売り方を人に移す |
| 3年目 | 8.0億円 | 218万円 | 1,592件 | 2.9人 | 組織で売る |
| 4年目 | 15.9億円 | 435万円 | 3,175件 | 5.8人 | 販路を増やす |
| 5年目 | 31.7億円 | 868万円 | 6,333件 | 11.6人 | 資金と管理体制 |
| 6年目 | 63.2億円 | 1,730万円 | 12,632件 | 23.1人 | 2つ目の事業 |
| 7年目 | 126.0億円 | 3,452万円 | 25,198件 | 46.0人 | M&Aと提携 |
| 8年目 | 251.3億円 | 6,886万円 | 50,264件 | 91.8人 | 経営チーム |
| 9年目 | 501.3億円 | 1.37億円 | 100,264件 | 183.1人 | 複数事業で伸ばす |
| 10年目 | 1,000.0億円 | 2.74億円 | 200,000件 | 365.3人 | 年商1000億円 |

必要な件数と人数は、「設定」の平均受注単価50万円・商談からの受注率30%・アプローチからの商談化率10%・営業1人1日50件（いずれも仮の値）で計算しています。単価や転換率が上がると、必要な件数と人数は減ります。年商が大きくなるほど、1人の行動量ではなく、組織・単価・販路で売上をつくる必要があることがわかります。

## 補足

- 日次ログ・経費ログ・案件パイプラインの「記入例」の行は集計されない。不要なら行ごと削除してよい。
- 経費は経費ログが正本。提出後に経費を追加・修正しても、月次集計には反映される（日次ログの費用欄は提出時点の記録）。
- 目標の数字は「設定」シートで変更できる。変更すると10年計画・本日の日報・月次集計が連動する。

## テンプレートを作り直す

```sh
pip install openpyxl
python3 build_template.py
```

`daily_report_template.xlsx` を上書きします。毎日やること（`HABITS`）、週・月にやること（`WEEKLY`）、10年の重点テーマ（`THEMES`）、勘定科目（`ACCOUNTS`）、案件フェーズと確度（`PHASES`）は `build_template.py` の先頭で変更できます。同じ内容なら毎回同じファイルが出力されます。
